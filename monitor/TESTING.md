# 验证范围

测试命令：

```powershell
python -B -m unittest discover -s monitor -p 'test_*.py' -q
```

本地测试环境为 **Windows x64 / CPython 3.12.14**。CI 和 `requirements.lock` 使用 CPython 3.12 x64；依赖哈希与官方 PyPI 元数据及本地对应 wheel 字节一致。此前 CI 误用 3.13，导致 Pillow 的平台 wheel 哈希不匹配，安装阶段终止；修复解释器选择，保留哈希校验。

干净的最小依赖虚拟环境中 **121 项合成测试通过**。覆盖：通用学校通知、关键词排除、规则顺序、字符归一化、片段上限、链接及部分联系信息清理、规则变更后的邮件拒绝、事件和邮件去重、可选价格示例（含 ON 5.64 磅严格低于 600 元与原门槛隔离）、邮件规格复核及旧队列兼容、事务回滚、游标恢复、Outlook 故障恢复逻辑、登录启动条件及配置启用边界。合成测试不读真实微信、不启动 Outlook、不发送邮件；不是实际群消息或收件到达证明。

早期部署版本曾用本机私有配置实测 Outlook 正常关闭后的按需启动、一封合成邮件进入目标收件箱、重复输入和队列重开没有第二次发送。真实配置、消息和实发报告没有加入仓库；这条历史记录不能替代新机器、新规则或新邮箱的部署验收。

公开副本需要在每台电脑上分别核验源读取、实际收件和登录启动。没有进行 Windows 重启验收，不保证其他微信／Outlook 版本兼容。持续运行的必要条件和故障处理见部署指南。
