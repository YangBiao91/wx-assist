# 场景规则与扩展

默认规则配置为 `generic`。在 `monitor/rules.local.json` 中选择一组适合目标群的规则；模板的所有规则默认关闭。一个实例只配置一个群，不能把多个群 ID 拼进同一字段。

## 学校通知

关注“考试安排”“报名截止”“截止报名”“提交材料”“停课通知”；排除“测试消息”“已取消”。这能匹配相应字面内容，不会推断所有“重要通知”，也不自动识别截止时间并建立日程。需要增加“家长会”“缴费”等内容时，把词加入本地列表并测试正反例。

## 特价与补货

关注“超好价”“超好忦”“限时优惠”“补货”；排除“已结束”“售罄”。这适用于不限品类的消息跟踪，不声称已经计算商品到手价、库存或性价比。异体字或拆字写法需要在 `any_keywords` 中列出实际关注的写法。

## 团队与社区

团队可关注“会议改期”“提交周报”“发布窗口”；社区可关注“停水通知”“活动变更”。每条规则有自己的显示名称、启用状态及排除词，按文件顺序选第一条命中，避免同一消息同时发多封邮件。

规则仅执行固定的字符串匹配。未知字段会报错，因此不要把 `regex`、任意脚本或自然语言 prompt 填进 JSON 并期待它运行。复杂分类可实现新的适配器，但应单独测试和说明能力。

## 可选：结构化商品价格示例

早期实现包含一个 `protein_deals` 示例适配器，位于 `monitor/deals.py`。在 `settings.local.json` 中显式设置 `rule_profile: "protein_deals"` 才会启用：ON 单件 5 磅人民币报价严格小于 580 元、ON 单件 5.64 磅严格小于 600 元、熊猫单件 5 磅严格小于 400 元，以及相应“超好价”写法提醒。

这些是该示例适配器的固定业务条件，不是通用 JSON 规则的价格表达式。通用模式不会自动启用它；如需任意商品价格、日期、报名对象等结构化规则，应实现专门解析和邮件复核，并加入边界测试。保留这个适配器是为了说明如何接入具体业务，项目本身不限定于蛋白粉或特价群。

## 完整案例：补剂群优惠 → 邮箱提醒

本例改写自一次实际的本地部署。以下群名、群内部 ID、目录和邮箱均为占位，不包含真实群消息或凭据。

### 用户提供什么

| 信息 | 本例中的输入 |
| --- | --- |
| 目标电脑 | 用户当前连接的 Windows 电脑，允许 agent 在项目目录完成安装、配置和测试 |
| 唯一目标群 | `<补剂优惠群的完整群名>`，只看这一个群 |
| 价格规则一 | ON 蛋白粉，单件明确 5 磅，人民币报价严格 `< 580` 元 |
| 价格规则二 | 熊猫蛋白粉，单件明确 5 磅，人民币报价严格 `< 400` 元 |
| 价格规则三 | ON 蛋白粉，单件明确 5.64 磅，人民币报价严格 `< 600` 元，600 元整不算 |
| 独立关键词规则 | 出现“超好价”“超好忦”及已支持的对应写法即提醒，不限品牌、规格和价格 |
| 邮件去向 | `<我的收件邮箱>`；通过本机经典 Outlook 中的 `<发件邮箱>` 发信 |
| 运行偏好 | 确认收到一封合成测试邮件后，持续监控后续新消息；监控、微信、Outlook 登录后自启 |
| 用户配合 | 完成微信和 Outlook 登录，配合本机读取授权；已有读取配置只提供本地路径 |

这里的报价来自群消息。价格或规格不明确时不当作已满足价格条件；关键词提及可以独立触发，提醒中应注明触发原因。

### agent 负责补齐什么

1. 检查 Windows、Python 3.12 x64、微信和经典 Outlook，选择部署目录并安装锁定依赖。
2. 在已授权的本机信息中核对唯一群 ID、微信账户目录和已有读取配置。群名有歧义或读取条件缺失时，请用户补齐，而不是猜测或读取其他群。
3. 将需求对应到 `protein_deals` 适配器，在被 Git 忽略的本地配置中写入实际群和邮箱；密钥保留在本机文件中。
4. 验证规则边界、读取、去重和恢复；向指定邮箱发一封合成测试邮件，并确认真实到达。
5. 按用户授权启用持续提醒和登录自启，观察成功轮次，交付状态与必要运行条件。

用户无需预先手工查找所有安装路径、内部 ID 或写好配置文件；这些属于 agent 的部署工作。用户仍需完成其本人账户的登录与必要授权。

### 对应到哪份配置

`monitor/settings.local.json` 的结构如下，占位内容由 agent 在本机核实后替换，不能直接用于启动：

```json
{
  "rule_profile": "protein_deals",
  "chat_id": "example@chatroom",
  "sender": "sender@example.invalid",
  "recipient": "recipient@example.invalid",
  "outlook_exe": "C:\\Program Files\\Microsoft Office\\Root\\Office16\\OUTLOOK.EXE"
}
```

`protein_deals` 已同时包含上述三个价格条件和独立关键词条件，不需要再用 `rules.local.json` 叠加另一套通用规则。价格门槛绑定品牌与单件磅数，5 磅与 5.64 磅分别判断；邮件发送前再次核对规格、重量和门槛。实际读取凭据放在 `monitor/credentials.local.env`，由 agent 按用户已有的本地授权处理，不能写进仓库或对话。

学校通知等纯关键词场景则保留 `rule_profile=generic`，在 `rules.local.json` 中填写“考试安排”“报名截止”等关键词及排除词。用户提供的需求形式相同，agent 选择的规则方案不同。

### 用什么例子确认规则正确

以下均为合成文字，不是实际群消息：

| 合成消息 | 预期结果 |
| --- | --- |
| `ON乳清蛋白粉，单件5磅，到手579元人民币` | 命中 ON 价格规则 |
| `ON乳清蛋白粉，单件5磅，到手580元人民币` | 不命中价格规则，等于门槛不算 |
| `ON乳清蛋白粉，单件5.64磅，到手599.99元人民币` | 命中 ON 5.64 磅价格规则 |
| `ON乳清蛋白粉，单件5.64磅，到手600元人民币` | 不命中价格规则，等于门槛不算 |
| `ON乳清蛋白粉，单件5磅，到手590元人民币` | 不命中价格规则，不套用 5.64 磅的 600 元门槛 |
| `熊猫乳清蛋白粉，单件5磅，到手399元人民币` | 命中熊猫价格规则 |
| `熊猫乳清蛋白粉，单件5磅，到手400元人民币` | 不命中价格规则 |
| `ON乳清蛋白粉，2.27kg，到手579元人民币` | 缺少明确“单件5磅”表述，不能作为确定符合的价格提醒 |
| `其他品牌限时活动，超好忦` | 命中独立关键词规则，不声称满足 ON／熊猫价格条件 |
| `ON乳清蛋白粉，单件5磅，优惠价格稍后公布` | 价格不明，不作为确定符合的价格提醒 |

### 怎样才算部署完成

原始本地部署曾验证：读取指定群的新文字消息；筛选价格边界和特殊关键词；Outlook 关闭后由脚本按需打开；一封明确标注的合成邮件进入目标 Gmail 收件箱；重复输入和队列重新打开没有造成第二次发送。登录自启做过快捷方式回读，没有实际重启电脑验收。

复制到另一台电脑时，agent 应重新取得这台电脑的证据：

- 实际工作进程存在，`last_success` 至少连续推进两次，群范围和规则方案正确。
- 目标邮箱确认收到对应测试编号；不能仅凭 Outlook 的 `submitted=true` 报告到达。
- 现有队列没有未解释的 `uncertain`／`blocked`，相同合成事件不重复发送。
- 用户要求的登录启动项已写入并回读；没有实际登录或重启测试时如实注明。

这份案例展示了从“用户描述需求”到“agent 配置并验收”的完整分工，真实部署的群信息、账户、密钥和收件证据仍留在本机。

## 扩展入口

1. 在新适配器中把文字转为事件结构，或扩展经过验证的配置模式。
2. 在 `matcher.py` 显式选择适配器，不根据群消息动态加载代码。
3. 在 `outlook_mailer.py` 添加相应的发送前复核，确保失效规则、错误范围和不充分证据不能进入邮件。
4. 覆盖正反例、边界、去重、恢复和消息片段最小化；通知通道必须由用户明确选择。

多群、语义分类、Webhook、SMTP、手机通知等都需要额外实现，目前不能把它们当已有能力写进部署完成报告。
